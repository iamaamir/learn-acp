Specials Board: Slash Commands

Promise: you will never send a command the Agent didn't advertise.

Framing: the specials board

The guest list from Lesson 0004 was printed once at the door. Slash commands are the specials board: rewritten nightly, sometimes mid-service. The Agent pushes available_commands_update — /test, /plan (needs a topic), /web (needs a query) — and the Client offers only those. Firing one is gloriously ordinary: the command string rides as plain text inside a normal session/prompt. No new rails — just a menu on top of the old ones.

Memorable label: “The Specials” — the menu changes; the ordering ritual never does.

Hands-on exercise (real code, 10 min)

  1. Run node --test from the course root. All tests should pass.
  2. Work the pass in node: 
    import { advertiseMenu, resolveCommand } from './src/acp-commands.mjs';
const menu = advertiseMenu([
  { name: 'test', description: 'Run tests' },
  { name: 'plan', description: 'Plan it',
    input: { type: 'text', hint: 'what to plan' } },
]);
console.log(resolveCommand(menu, '/test'));       // ok, fires
console.log(resolveCommand(menu, '/plan'));       // missing input + hint
console.log(resolveCommand(menu, '/dance'));      // unlisted, never send
  3. Stretch (menu diff): write diffMenus(oldMenu, newList) returning { added, removed, changed } names, and log a one-line "specials changed" summary a Client could show. Test all three cases.

Payoff

Interview Q: “How do slash commands travel? New method?”

Model answer: “No new rails. The Agent advertises availableCommands via a session/update notification — name, description, optional typed input. The Client validates locally: listed, and input present when required. Firing is an ordinary session/prompt whose text is /name args. Unlisted input never touches the wire — same guest-list discipline as capabilities, just re-posted nightly.”

Pro tip (production): re-render the palette on every available_commands_update, and keep the last menu per session. Stale palettes are how users order off-menu — the #1 slash-command support ticket.

With this, you can now build: a command palette that can't misfire — advertised-only, input-checked, fired as plain prompt text.
